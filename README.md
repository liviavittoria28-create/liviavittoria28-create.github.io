# Portfólio · Lívia Vittoria

Site pessoal de **Lívia Vittoria, desenvolvedora Full Stack** e estudante de ADS na FATEC São Caetano do Sul.

**No ar:** https://liviavittoria28-create.github.io

## O que tem

- Identidade visual *light tech*: monograma L, paleta azul (`#1769AA`, `#58A6E7`) e diagrama animado de interface → API → dados.
- Projetos organizados por categoria (Full Stack, Engenharia de Software, Front-end, Estudos), com filtro.
- Lista de repositórios carregada da API pública do GitHub. Ficam de fora os repositórios privados e arquivados, protótipos e repositórios em preparação. Se a API falhar, aparecem cartões fixos.
- Responsivo (celular, tablet e computador), navegação por teclado, foco visível e respeito a `prefers-reduced-motion`.

## Tecnologias

HTML, CSS e JavaScript puros, num único `index.html`, sem build. Ícones e diagrama em SVG.

## Executar localmente

```bash
python3 -m http.server
# abra http://localhost:8000
```

## Estrutura

```
index.html          página completa (estilos e scripts inclusos)
assets/monogram.svg monograma L (também usado como favicon)
assets/img/         capturas reais dos projetos (Agenda Expert e VIVA+ com dados fictícios)
```
